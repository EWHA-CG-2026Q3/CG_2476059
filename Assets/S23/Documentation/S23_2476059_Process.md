# S23 곡면 과제

2476059 김유진

## 수행 과정 및 방법 (5문장)

Unity Splines의 Spline Container에 곡선 경로를 만들고, Spline Extrude로 원형 단면을 확장하여 덩굴 줄기를 구성하였다.
네 모서리 위치를 u와 v 방향으로 보간하는 bilinear patch를 직접 구현하고, 정점에 UV를 배치한 뒤 배포된 잎 텍스처를 입혀 휘어진 나뭇잎을 만들었다.
같은 방식을 정자의 캐노피에도 적용하여 서로 마주 보는 두 모서리의 높이를 다르게 설정하고, Cull Off와 뒷면 법선 반전으로 위와 아래에서 모두 보이게 하였다.
Toon·Outline·VertexColor 재질을 Mesh Renderer에 각각 넣은 비교 물체에서는 효과가 하나의 계산으로 합쳐지지 않아 마지막 표면 재질의 부드러운 명암이 나타나고 Toon의 단계적인 명암이 유지되지 않는 것을 확인하였다.
이를 해결하기 위해 첫 번째 Pass에서 정점 색상과 Toon 조명을 함께 계산하고 두 번째 Pass에서 외곽선을 그리는 하나의 셰이더를 작성하여, 최종 물체에 재질 하나로 세 효과를 적용하였다.

## 재질을 3개 넣었을 때 다른 이유

Mesh Renderer의 재질 목록은 셰이더 기능을 합치는 목록이 아니라 SubMesh의 그리기와 연결된다. 이 비교 Mesh는 SubMesh가 하나이므로 추가 재질이 같은 Mesh를 다시 그리며, 각 셰이더가 별도로 계산한 결과가 깊이 검사와 그리기 순서의 영향을 받는다. 따라서 Toon의 명암 계산에 VertexColor가 자동으로 곱해지는 것이 아니며, 이 장면에서는 VertexColor 재질의 부드러운 명암이 보인다. 통합 셰이더는 첫 Pass 안에서 두 계산을 결합하고, 별도의 두 번째 Pass에서 외곽선만 그린다.
